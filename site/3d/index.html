히트맵과 효율 계산 방법

r(x,y) = Σ4 sides exp(−dk/ℓ)
g(x,y) = r(x,y) / ⟨r⟩
Alocal(x,y) = Abulk + S · P/A · g(x,y)
G = Alocaln + Bn² + Cn³
EQE(x,y) = ηinj · Bn²/G · LEE
ηI = EQE · 683V(λ)hc/(πqλ)　[cd/A]

정규화한 공간 가중치 g의 면적 평균은 1이므로, 국소 측벽 SRH 항의 평균은 기존 ABC 모델의 S·P/A와 같습니다. ℓ은 측벽 영향이 안쪽으로 감쇠하는 폭을 조절하는 사용 변수입니다. 전류밀도는 면내에서 균일하다고 가정하고, 국소 EQE의 면적 평균을 전체 EQE로 사용합니다.

실제 3D 전류 확산, 캐리어 이동, 온도, 광추출을 푸는 해석은 아닙니다. 문헌의 공간발광 분포와 유사한 형태를 탐색하는 축약 근사이며, ℓ이나 계수는 사용자 측정값으로 보정해야 합니다.
