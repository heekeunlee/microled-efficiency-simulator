# Micro-LED Efficiency Simulator

마이크로 LED의 픽셀 크기, 전류밀도, 측벽 표면 재결합 속도와 재결합 계수를 바꾸며 내부양자효율(IQE), 외부양자효율(EQE), 초당 출광 포톤 수를 비교하는 브라우저 기반 축약 시뮬레이터입니다.

## 모델

정상상태 ABC 재결합 모델에 정사각 픽셀의 측벽 손실 근사 항을 더합니다.

```text
G = A_eff n + B n² + C n³
A_eff = A_bulk + S · 4 / w
IQE = B n² / G
EQE = injection_efficiency · IQE · light_extraction_efficiency
photon_rate = input_current · EQE / elementary_charge
```

캐리어 밀도 `n`은 양의 정상상태 해를 이분법으로 구합니다. `A_bulk`는 벌크 SRH 재결합 계수(s⁻¹), `B`는 방사 재결합 계수(cm³/s), `C`는 오제 재결합 계수(cm⁶/s), `S`는 표면 재결합 속도(cm/s), `w`는 픽셀 한 변(cm)입니다.

초기 파라미터는 저전류에서 이 축약 모델의 EQE가 높아지도록 각 슬라이더의 효율 유리 방향으로 설정했습니다. 특히 전류밀도 0.1 A/cm², 큰 픽셀, 낮은 SRH·오제 손실과 높은 주입·방사·광추출 효율을 사용합니다. 이는 실제 소자의 최적 설계나 달성 가능한 성능을 뜻하지 않습니다. 실제 소자 분석에는 측정한 EQE–전류밀도 곡선과 재료·계면 파라미터로 보정해야 합니다.

## 모델의 범위

- 균일한 캐리어 밀도와 전류 분포를 가정합니다.
- 전류 누설, 자가 발열, 분극 전계, 광자 재활용과 파장에 따른 광추출 변화를 풀지 않습니다.
- `4 / w`는 정사각 픽셀의 둘레/면적 근사입니다. 나노와이어, 원형 또는 다른 형상에는 별도 형상식이 필요합니다.
- 계산 결과는 설계 경향 비교용이며 보정되지 않은 절대 효율 예측값이 아닙니다.
